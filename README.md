# StudentManagementSystem
Java面向对象版本学生管理系统，控制台实现增删改查

## ✨项目介绍
基于Java面向对象思想开发，封装Student实体类，对学号、姓名、年龄、性别、成绩做属性合法性校验。
ArrayUtils工具类封装数组操作，控制台菜单交互。

## 📂文件结构
src/演示版
├─ Student.java        学生实体类，封装属性+校验
├─ ArrayUtils.java     数组工具类
├─ StudentView.java    控制台菜单视图
└─ Test.java           程序入口main方法

## 💻开发环境
- JDK 8 及以上
- IDEA

## 📌功能清单
- 添加学生
- 查看全部学生信息
- 根据学号查找学生
- 根据学号修改信息
- 根据学号删除信息
